# JEAuditFlow 7.5.0 发布说明

交付日期：2026-11-10，Asia/Shanghai。

## 需求完成情况

1. 自动建立 AuditFlow 与 JiraFlow 的项目对应关系，幂等同步 NC，完整分页读取问题，并提供显式的 JiraFlow issue 导入操作。同步保留评估员编辑、独立验证和正式关闭链。
2. 修复浏览器扩展顶部四组菜单始终展开的问题。支持点击切换、互斥展开、外部点击、Escape、ArrowDown 和 Tab，修复包内缺少的 AI 助手静态资源。
3. NC / Finding 跟踪从“范围与资料”移至“记录表单”，保留登记、筛选、编辑、状态、关闭链、同步与导入。
4. 导入保留完整工程条目，显示筛选与正式评分资格分开。取消表格行列、文档条目及 PDF 页数的旧截断，保留架构图片索引。处理单行双列表格中的原始需求定义卡，补回旧导入数据遗漏的定义正文，并保持既有 ID、评估员判断和追溯关系。嵌套表格按实际单元格提取，定义正文只展开一次，保留合法的后续元数据列。自动恢复执行后，评估员主动移除的条目不会被反复恢复。
5. “记录合并”增加完整证据目录，提供稳定过程编号、原始 ID、来源文件、定位、实例、已确认引用、搜索、多条件筛选、分页及原文预览。
