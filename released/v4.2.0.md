# JEAuditFlow 4.2.0

> 本版要点取自构建产物的官方清单字段（`artifacts/release-manifest.json`、
> `artifacts/backend-release-manifest.json`，由 `build.ps1` / `build-backend.ps1` 写入），
> 为其中英文 `notes` 字段的忠实翻译，不额外补充未经证实的功能描述。
> 完整校验和见 [`SHA256SUMS.txt`](SHA256SUMS.txt)。

## 本版要点

- **FileAnalyst 离线韧性**：增强 FileAnalyst 在离线 / 服务不可达场景下的容错与恢复能力。
- **后端状态可见性**：桌面端可观测后端服务的运行与健康状态，异常时给出明确反馈。
- **英文界面本地化**：补齐 Tree 视图与需求（requirements）区域的英文翻译。
- **共享数据契约**：术语表（glossary）与发现项（findings）使用统一的数据契约。

## 运行方式（桌面便携版）

解压 `JEAuditFlow-4.2.0-Portable-win-x64.zip` 到任意目录，运行其中的 `JEAuditFlow.exe`，
使用本机邮箱账号注册或登录。无需安装、无需管理员权限、不写注册表、不修改 `PATH`。
需要 Windows 端已具备 Microsoft Edge WebView2 Runtime。
