# JEAuditFlow 5.55.0

JEAuditFlow 5.55.0 publishes the updated 5.5 runtime packages for the
browser-extension and backend-server channels.

## Included

- Browser extension package aligned to the 5.5 runtime contract.
- Backend package rebuilt from the supplied JEAuditFlow 5.5.0 backend package.
- English-mode rendering fix for TUV audit issue reference candidates so
  bilingual source descriptions do not leak Chinese text into the English view.
- Release metadata records runtime compatibility `5.5.x` and capability
  version `12.3.0`.

## Verification

- `unzip -tqq` passed for both release assets.
- Backend package SHA-256 manifest validation passed.
- Backend server checks and tests passed locally.
- FileAnalyst checks and tests passed locally.
- English localization regression coverage passed locally.

This release was validated in the local workspace. Production deployment,
cloud database migration, and clean-machine acceptance remain separate
operations.
