## Included

- **Backend/API:** Node.js collaboration API, FileAnalyst service package, and JiraFlow 2.1.0 runtime. Production collaboration mode requires MySQL; FileAnalyst runs as a separate service and stores attachments in MySQL.
- **Browser extension:** unpacked-loadable Chrome/Edge extension, version 7.4.0, capability contract 12.3.0. The extension can connect to the matching backend through its Collaboration settings.
- **ASPICE review workflow:** fixed project phase navigation; evidence inventory grouped by source file; atomic document extraction with SYS/SWE/MAN/SUP process candidates; assessor-adjustable process and evidence role per item; candidate JSON exchange for ASPICE Audit Master and AI review.
- **Hosted connection fix:** HTTPS pages no longer probe a visitor's `127.0.0.1` or `localhost` using stale browser storage values. Hosted discovery uses same-origin HTTPS paths; local loopback discovery remains available to local desktop pages and the extension.
- **Credential boundary:** no database password, provider API key, or user evidence is embedded in either package. Configure secrets on the backend host only.

## Install

1. Install the backend on a Linux host with Node.js 20 or later, Java 21, and MySQL 8.4.
2. Install the browser extension in Chrome or Edge using Developer mode and **Load unpacked**.
3. Configure the extension's Collaboration endpoint as the backend's public HTTPS origin, sign in, and approve the browser's optional host permission prompt for that origin.

The full commands, service configuration, reverse-proxy example, verification checks, and troubleshooting steps are in the attached installation guide. Keep MySQL and service ports private; expose HTTPS only.

The auto-generated GitHub **Source code** archives are not install packages. Use the versioned backend and browser-extension assets above.

## Upgrade note

Do not point 7.4 at a 6.8 database volume as an in-place upgrade. Back up the existing service and database first, provision a separate 7.4 database, and plan any data migration as a separate, verified operation. The packages do not automatically migrate 6.8 project data.

AI output remains advisory. Formal ASPICE scope, evidence roles, ratings, assessor confirmation, and closure decisions remain under authorized human control.
