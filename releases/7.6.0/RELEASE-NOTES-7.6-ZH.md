# JEAuditFlow 7.6.0

发布日期：2026-11-11。

## 本次更新

1. 右下角反馈入口提供页面图像、图片上传、画笔、矩形、箭头、遮挡、撤销与草稿。提交前显示文字、选中图片和当前站点接收位置。其他图片保留在本机。
2. 默认地址进入登录页。左侧为欢迎信息和指南，右侧为账号密码；宣传页继续通过明确链接访问。
3. Process Reference 按界面语言显示，包括可点击 BP/GP、过程图节点、连线和参考面板。过程标识与模型原文保留。
4. 右上角增加 Jira/Confluence 桥接。Mac 连接器主动连接公网服务，固定访问本机 8080/8090。会话受账号权限、独立令牌、心跳和撤销控制。
5. 树状视图证据区域增加可滚动列表与筛选面板，支持过程、条目类型、证据角色和来源等条件。
6. 上传文件按用途分类。工程资料进入证据候选流程，审核问题表进入独立问题候选库；混合或不明确文件保留待确认。后台任务显示进度，支持取消、重试和恢复。
7. AI Harness 记录过程、BP/GP、实际证据编号和定位、provider/model、执行状态与候选问题。模型未配置时显示未推理，不生成冒充模型结果的评分。正式结论仍由评估师确认。
8. 修复 TÜV ASPICE Audit Issue Ledger 2026 模板服务映射和报告封面导出错误。报告通过现有正式范围、证据角色和人工确认规则生成。

## 数据与发行

7.6 使用 `jeauditflow_760`、卷 `jeauditflow_760_mysql_data` 与独立端口。7.5 数据不自动迁移，也不覆盖。

数据库包提供空库结构、迁移与健康检查工具。安装包和公开源码包排除原始客户审核数据、个人账号数据库、上传文件、凭据和运行日志；内置客户数据适配器保留兼容接口与空集合。需要原项目数据时，应在本机通过审核后的备份和迁移流程处理。

源码包包含实际客户端、API、FileAnalyst、JiraFlow Java、启动器和所选合成回归测试。它来自本次发行的校验目录，不包含开发工作区中的其他未提交修改。

## 已知边界

- 真实 DeepSeek 调用可能计费。本次验证使用本地模拟服务，不把协议测试宣称为真实模型评估成功。
- 公网访问本机服务需要公网服务器安装相同版本、HTTPS 和运行中的 Mac 连接器。本次本机安装不自动部署 ECS、改 DNS 或开放端口。
- 桥接为有界 HTTP 中继：请求 2 MiB、响应 8 MiB、每分钟 240 请求、32 个在途请求；会话心跳有效期 120 秒，最长 8 小时。Atlassian SSO、WebSocket 协作和大附件需要另行验证。
- macOS 启动器采用本机临时签名，未做 Apple 公证，也未宣称完成干净 Mac 的安装验收。

具体测试、安装状态和文件校验结果以发行目录中的 `VERIFICATION-7.6.0.json` 与 `SHA256SUMS.txt` 为准。
