# AuditFlow 6.0 release notes

- Fixed the Conduct manual-rating selector so row selection no longer closes it.
- Added remembered column widths, column visibility, editable header labels, and
  a reset control for Conduct, Current Audit Status, Evidence, Versions,
  Close and Reports, and Helix import.
- Added Current Audit Status project deletion with an explicit confirmation.
- Added per-version comparison for BP/GP rating changes, improvements,
  regressions, and remaining gaps.
- Added five-column Helix presentation: Tag, Summary, REQ/RE/TASK Type,
  Status, and Document List. Double-click an item to inspect its details.
- Added a local Codex bridge launcher and richer Codex context: uploaded
  excerpts, parsed tables, Helix details, evidence links, open findings,
  traceability, and recent version direction.
- Updated the embedded aspice-audit-master header with an original assistant
  mascot vector based on the supplied visual reference.
