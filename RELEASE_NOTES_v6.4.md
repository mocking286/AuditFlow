# AuditFlow v6.4

## Project-level workflow

- The dashboard no longer displays the global “Audit Workflow live funnel”.
- Each project now contains a collapsible “Assessment questions & project plan” panel with all nine assessment-flow phases.
- Clicking a phase opens that project's corresponding workspace and exposes the current completion gap.

## UI fixes

- The Close & report phase icon has a visible outline.
- The dashboard trash action stays on the same row, immediately to the right of the open-project arrow.
- The project workflow panel is collapsed by default to preserve the user's working view.
