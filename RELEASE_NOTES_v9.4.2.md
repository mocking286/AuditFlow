# AuditFlow v9.4.2 Release Notes

## User-facing changes

- Replaced AuditFlow branded extension, popup, workspace, help, landing-page and Audit Master icon assets with the supplied Codex-style mark.
- Introduced a dedicated Codex Assessment Assistant icon with the blue data-flow and amber-node visual language of the supplied reference image.
- Made the `Trace relations` Finding list independently vertically scrollable. All Finding cards and their six relation actions remain accessible when many relations exist.

## Compatibility

- The extension version is `9.4.2`.
- The workspace database schema remains at version 57: current evidence, trace links, findings, ratings and audit records remain in place.

## Verification

- Manifest JSON, JavaScript syntax, icon dimensions, version strings and archive contents are checked before packaging.
